# 聲律發蒙

把豆瓣日记 **《聲律發蒙》（劉節五卷本）** 校訂本，做成可全屏放映的 HTML 幻灯片与可打印的 PDF：
**竖排右起、原文五卷全文**，注解与翻译逐篇推进。

| | |
|---|---|
| 底本 | 元祝明撰　潘瑛續　明劉節校補（《四庫全書總目》卷137 著錄） |
| 规模 | 五卷 · **106 韻 · 376 段** |
| 成品 | 5 册 HTML（219 页）＋ 6 份 PDF（含 220 页合訂本） |
| 注譯 | 一東已就绪（4 页），其余 105 韻逐篇推进 |

## 二、快速开始

```bash
make            # 生成五卷原文 → build/卷一.html … 卷五.html + index.html
make pdf        # 导出 PDF：五卷分册 + 五卷合訂本（约 35 秒）
make check      # 全量质检：源文本体例 + 排版（交付前必跑，须 0 问题）
make annot      # 生成一東注譯样张（4 页）
make slots      # 生成带「注解占位页」的版本
make sample     # 逐页截图到 build/png/
```

打开 **`build/index.html`** 即为总目，点入任意一册可直接全屏放映。

### 放映操作

| 操作 | 效果 |
|---|---|
| `←` `→` / `↑` `↓` / `空格` / `Enter` | 翻页 |
| 点击画面 | 右侧 78% 前进，左侧 22% 后退 |
| 触摸左右滑 | 翻页 |
| `Home` / `End` | 首页 / 末页 |
| `F` | 全屏 |
| URL `#p12` | 直达第 12 页（可分享单页） |

版面固定 **1280×720（16:9）**，按窗口等比缩放；16:9 屏幕全屏后无黑边。
