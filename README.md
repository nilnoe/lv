# 聲律發蒙 · 幻燈

把豆瓣日记 **《聲律發蒙》（劉節五卷本）** 校訂本做成可放映的 HTML 幻灯片：
竖排右起的原文五卷 + 逐篇推进的注譯页码。

- **原文**：全五卷 106 韻 376 段 → 5 个 HTML（共 212 正文页）
- **注譯**：逐篇推进中（已完成样张：一東）

---

## 快速开始

```bash
make            # 生成五卷原文 → build/卷一.html … 卷五.html + index.html
make check      # 全量排版质检（必须 0 问题）
make annot      # 生成一東注譯样张（4 页）
make slots      # 生成带"注解占位页"的版本
make sample     # 逐页截图到 build/png/
```

打开 `build/index.html` 即为总目；任意一册可直接全屏放映。

### 放映操作

| 操作 | 效果 |
|---|---|
| `←` `→` / `↑` `↓` / `空格` / `Enter` | 翻页 |
| 点击画面 | 右侧 78% 前进，左侧 22% 后退 |
| 触摸左右滑 | 翻页 |
| `Home` / `End` | 首页 / 末页 |
| `F` | 全屏 |
| URL `#p12` | 直达第 12 页（可分享单页） |

版面固定 1280×720（16:9），按窗口等比缩放；16:9 屏幕全屏后无黑边。
