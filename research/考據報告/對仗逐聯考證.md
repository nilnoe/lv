# 《聲律發蒙》（劉節五卷本）卷一「一東」逐聯對仗分析

## 〇、檢索與版本說明（先交代依據，後文所有引錄皆有出處）

**版本**：《四庫全書總目提要》卷一百三十七著錄：

> 《聲律發蒙》·五卷（內府藏本）
> 元祝明撰，潘瑛續，明劉節校補。據高儒《百川書志》雲，《聲律啟蒙》二卷，元博陵安平隱者祝明文卿撰。自一字七字至隔句各押一韻，對偶渾成，音響自合，共九十首，則此編前二卷為明書，後三卷瑛所續也。瑛不知何許人。節有《春秋列傳》，已著錄。其書每一韻先列韻字與注，而後列雜言對屬之語。蓋為初學發蒙而作，無所當於著述。

〔案〕此條極重要，一則說明「劉節五卷本」實為元祝明原撰、潘瑛續、劉節校補；二則「自一字七字至隔句各押一韻」正是本次兩段正文的體製（2字→3字→4字→5字→7字→隔句），下文逐聯分析即依此階梯展開。

**平仄依據**：本次分析自行建構《平水韻》全表（上平／下平／上聲／去聲／入聲五部），逐字比對兩段全部用字，**入聲一律歸仄**。平仄標記中凡屬入聲者以「**仄**(入)」標出。

**押韻**：其一全押「一東」韻（東、中、風、功、公、同、濛、窮、繩\*、窮）；其二押「東、空、蟲、弓、東、宮、紅、翁」。\*「繩」屬下平蒸韻，是隔句對的句腳例外，見第八聯說明。

## 一、其一（8 聯）

### 第 1 聯　南對北，北對東

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**（兼**反對**）；且兩句之間構成**當句對的疊用**（南—北—東三方位交錯成對） |
| 詞性義類 | 南（名·方位）／北（名·方位）；北（名·方位）／東（名·方位）——皆「方位對方位」 |
| 為什麼能對 | 三者同屬方位範疇，構成同一語義場內的 **反義／異義對**。南—北為正反，北—東為相鄰異向；以「北」字居中頂針（上句末字即下句首字），形成「A對B，B對C」的連鎖，是蒙書最典型的「方位輪轉」練習 |
| 平仄 | 南(平)對 北(仄·入)；北(仄·入) 對 東(平)。**合「平對仄」**（第1、2字位皆反） |
| 修辭效果 | 兩句共 6 字而含 3 方位，學生一讀便知「方位可兩兩相對」，並練「北」字讀入聲（仄），避免以今音誤判為平 |

### 第 2 聯　物外對寰中

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**（兼**反對**） |
| 詞性義類 | 物（名·人事/泛指）／寰（名·地理）；外（名·方位）／中（名·方位）。整體皆「名＋方位」**偏正結構** |
| 為什麼能對 | 關鍵在 **「外／中」反義相對**；「物外」謂超然物象之外，「寰中」謂寰宇之內，兩者同屬**空間範疇**、同一構詞法（名詞＋方位詞），故為工對。「物外」出《世說新語》等魏晉語彙（「物外之趣」），「寰中」為「天下」之常語 |
| 平仄 | 物(仄·入) 外(仄·去)／寰(平) 中(平)。句內「仄仄／平平」相對，**平仄全反** |
| 修辭效果 | 示範「方位詞可作對眼」，並教抽象空間概念（方外／世內）之別 |

### 第 3 聯　君臣對父子

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**（兼**正對**，事異義同而相成） |
| 詞性義類 | 君／父（名·人事·尊長）＋臣／子（名·人事·卑幼）；皆**並列結構** |
| 為什麼能對 | 二者同屬**人事倫常**範疇，構詞方式一致（身分名詞並列），且內部各有「尊—卑」層級對應（君:臣＝父:子）。此即《文心雕龍·麗辭》所謂「正對者，事異義同者也」——兩句各舉一事，義理同歸於倫常 |
| 平仄 | 君(平) 臣(平)／父(仄·上) 子(仄·上)。此聯**末字俱仄，句腳未成平仄相對**；但第1字「平對仄」已立。蒙書只求字面平仄相對、不嚴守近體「上仄下平」 |
| 修辭效果 | 蒙學的「倫理＋屬對」雙重教學：既識君臣父子之序，又練並列結構之對。—〔按〕此為五卷本蒙書與近體律詩聲律要求不同之顯例，宜向學生說明 |

### 第 4 聯　海嶽對雷風

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**（兼**正對**）；**用典對**（事對性質） |
| 詞性義類 | 海／雷（名·地理 vs 名·天文）；嶽／風（名·地理 vs 名·天文）。整體皆**並列結構** |
| 為什麼能對——**《周易·說卦》典之查證** | 用戶所提「雷風相薄／山澤通氣」**確實成立**。《易傳·說卦》第三章原文：<br>「**天地定位，山澤通氣，雷風相薄，水火不相射。八卦相錯，數往者順，知來者逆。是故易逆數也。**」<br>同篇第六章又云：「故水火相逮，**雷風不相悖，山澤通氣**，然後能變化，既成萬物也。」（以上俱見《易傳·說卦》）<br>〔判定〕此典**成立但須分層說明**：①「**雷風**」是《說卦》成對固定語（雷風相薄、雷風不相悖）；②「海嶽」並非《說卦》原詞，而是「**山澤**」的擴展——嶽即山、海可視為澤之極大者，故「海嶽」與「雷風」同構於八卦「山澤／雷風」兩組對待。③ 因此本聯可判為**「事對」性質的工對**：以《易》八卦對待之典為底，字面又「海—雷」「嶽—風」一地理一天文，義類相鄰而不同門，屬工對而非死對。<br>④ 若嚴格依王力「義類越近越工、同門為工對」之說，「海嶽」（地理門）對「雷風」（天文門）為**鄰類**，判工對亦可，判**寬對**亦通；本文主**工對**，並註「義類跨門，從寬亦可」（存疑處已明示） |
| 平仄 | 海(仄·上) 嶽(仄·入)／雷(平) 風(平)。**平仄全反** |
| 修辭效果 | 由「人事」轉入「天地自然」，音律上以「仄仄／平平」全反作示範；同時暗植《易》學常識 |

### 第 5 聯　堯舜德，禹湯功

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**（兼**正對**） |
| 詞性義類 | 堯、舜／禹、湯（名·人物，皆上古聖王）；德／功（名·抽象·人事）。句式皆「**並列人名＋抽象名詞**」 |
| 為什麼能對 | ①人物同類：堯舜為「禪讓」之聖，禹湯為「征誅」之聖，兩組並舉而不重複；②德／功同屬**抽象人事範疇**且常連言（「功德」）；③結構完全平行 |
| 平仄 | 堯(平) 舜(仄·去) 德(仄·入)／禹(仄·上) 湯(平) 功(平)。**三字位全反**（平仄仄／仄平平），是標準的「平對仄、仄對平」 |
| 修辭效果 | 三字對是蒙書核心單元，一句之中已含「名＋名＋名」節奏；教學上兼收歷史人物常識 |

### 第 6 聯　孔子對周公

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**（兼**正對**） |
| 詞性義類 | 孔／周（名·姓氏）＋子／公（名·尊稱/爵稱）；皆**人物專名**，同屬人事門 |
| 為什麼能對 | 孔子與周公是儒家「道統」上並舉的兩極（一為「集大成」之師，一為「制禮作樂」之相），專名對專名、結構對結構，且音節皆「仄平／平平」相參 |
| 平仄 | 孔(仄·上) 子(仄·上)／周(平) 公(平)。**平仄全反** |
| 修辭效果 | 與上聯同屬「人物」主題，形成「聖王—聖賢」的意義層遞 |

### 第 7 聯　六經千古在，五典百王同

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**（兼**正對**）；核心為**數目對** |
| 詞性義類 | 六／五（數目）、經／典（名·文事）、千／百（數目·約數）、古／王（名·時令 vs 名·人物）、在／同（動/狀·虛實）。整體皆「數＋名＋數＋名＋謂」 |
| 為什麼能對 | ①「六／五」「千／百」為**數目對數目**；②「經／典」同義連類（皆典籍）；③「千古」為時間，「百王」為歷代帝王，以**時間 vs 人物**相配，屬鄰類對，從寬則工；④末字「在／同」皆表狀態，屬虛字／動詞相對。<br>〔按〕「六經」「五典」皆常見成詞（「六經」為《詩》《書》《禮》《樂》《易》《春秋》；「五典」見《左傳·昭公十二年》「**是能讀三墳、五典、八索、九丘**」之語，舊注以為五帝之書）。**本聯是否直接化用某一固定成句，未見確證，標「存疑」**；可確證者為「六經」與「五典」在明代蒙書中已成對舉套語 |
| 平仄 | 六(仄·入) 經(平) 千(平) 古(仄·上) 在(仄·上)／五(仄·上) 典(仄·上) 百(仄·入) 王(平) 同(平)。**第2、4、5字位相對**（平/仄、仄/平、仄/平）；第3字「千(平)/百(仄)」亦相對——全句五字位皆成「平對仄、仄對平」。唯上聯句腳「在」為仄，下聯句腳「同」為平，**符合「上仄下平」** |
| 修辭效果 | 由三字進為五言，示範「數目字可作整聯骨架」；同時灌輸經學常識 |

### 第 8 聯（隔句對）　書代結繩，闡人文於有象／圖呈畫卦，開道統於無窮

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**中的**隔句對**（隔句相對）；兩分句各有**當句對**之勢（上聯內部「書代結繩」與「闡人文於有象」為一事之因果鋪陳，非嚴格自對，故只宜稱隔句對） |
| 詞性義類 | 書／圖（名·文事）、代／呈（動）、結繩／畫卦（動賓·事典）、闡／開（動）、人文／道統（名·抽象）、於／於（介·虛字）、有象／無窮（形/名·抽象）。逐詞對應 |
| 為什麼能對 | ①「書代結繩」用《易·繫辭下》「**上古結繩而治，後世聖人易之以書契**」之典；②「圖呈畫卦」用《易·繫辭上》「**河出圖，洛出書，聖人則之**」及伏羲畫八卦之典（「圖」「書」對舉亦《易》語）；③「有象／無窮」以「有／無」反義為對眼，「象」（具體形象）對「窮」（極盡），屬**反義對**；④「人文」出《易·賁卦·彖》「**觀乎人文，以化成天下**」，「道統」為儒家統緒之詞，二者同屬抽象人事 |
| 平仄 | 書(平) 代(仄·去) 結(仄·入) 繩(平)，闡(仄·上) 人(平) 文(平) 於(平) 有(仄·上) 象(仄·上)／圖(平) 呈(平) 畫(仄·去) 卦(仄·去)，開(平) 道(仄·上) 統(仄·去) 於(平) 無(平) 窮(平)。<br>——上聯第2/3字「代結（仄仄）」對下聯「呈畫（平仄）」：第2字平仄相對，第3字同為仄（**失對**）；第7/8字「有象（仄仄）」對「無窮（平平）」全反。整體**以「有／無」「象／窮」「闡／開」為主對眼，平仄大致相對，局部（第3字）未成反**，屬蒙書隔句對常見的寬處 |
| 修辭效果 | **全篇最高階**：以《易》學兩個開創性事件（書契代結繩、河圖畫卦）為對，把屬對訓練與「文明起源／道統」敘事合一。教學上示範：長句對不必字字死對，須先立**對眼**（有象/無窮），再求其餘 |

> 〔其一聲律總評〕8 聯中，第 1、2、4、5、6、7 聯六聯做到「平對仄、仄對平」；第 3 聯末字俱仄（句腳未反），第 8 聯第 3 字失對。**全篇無典型拗救**（蒙書非律詩，無「孤平」「三平調」之拘）。規律是：**字數越短（2—5字）聲律越嚴，越長（隔句）越寬**，此即蒙學由嚴入寬之階梯。

## 二、其二（8 聯）

### 第 1 聯　雲對雨，雪對風

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**（兼**正對**）；兩句相連亦可視為**當句對**式的一方位／氣象排比 |
| 詞性義類 | 雲／雪（名·天文）、雨／風（名·天文）。四者同屬**天文門** |
| 為什麼能對 | 雲雨風雪皆為天氣現象，**同門同類**，是工對最典型的「天文對天文」；字面上「雲—雨」為「聚—降」的因果鄰近，「雪—風」為冬日並見，義類相親 |
| 平仄 | 雲(平) 對 雨(仄·上)；雪(仄·入) 對 風(平)。**平仄全反**，且與第1聯（南對北）同型，可對照教學 |
| 修辭效果 | 承接其一第1聯的方位對，換成「天文對」，讓學生比較不同義類的同型句式 |

### 第 2 聯　晚照對晴空

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**（兼**正對**／兼**反對**色彩） |
| 詞性義類 | 晚／晴（形·時令 vs 形·天文）、照／空（名·天文/光象 vs 名·天文）。皆**偏正結構** |
| 為什麼能對 | 「晚照」為落日之光，「晴空」為無雲之天，同屬**天象門**；修飾語「晚（時間）／晴（天氣）」義類相鄰，「照（有光）／空（無形）」形成**虛實相映**，故兼有正對之和諧與反對之張力 |
| 平仄 | 晚(仄·上) 照(仄·去)／晴(平) 空(平)。**平仄全反**。此為三字對，**三位皆反**，是典型的工整短聯 |
| 修辭效果 | 示範「三字對」中形容詞＋名詞的搭配，並教「仄仄／平平」全反模式 |

### 第 3 聯　來鴻對去燕，宿鳥對鳴蟲

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**（「來鴻／去燕」兼**反對**；「宿鳥／鳴蟲」兼**正對**）；兩分句並列，可視為**當句對的連用**（來—去、宿—鳴各自成對） |
| 詞性義類 | 來／去（動·動作）、鴻／燕（名·動物·禽）、宿／鳴（動·動作）、鳥／蟲（名·動物·禽 vs 動物·蟲）。整體「動＋名」**動賓/偏正結構** |
| 為什麼能對 | ①「來／去」為**反義動詞對**，是「反對」的典範（理殊趣合）；②鴻與燕同屬**禽鳥門**、鳥與蟲同屬**動物門**，義類相鄰；③「宿（靜）／鳴（動）」為動靜相對，使下句由空間（燕鴻）轉入聲音（蟲鳴） |
| 平仄 | 來(平) 鴻(平) 對 去(仄·去) 燕(仄·去)；宿(仄·入) 鳥(仄·上) 對 鳴(平) 蟲(平)。<br>——「來鴻」平平對「去燕」仄仄：**平仄全反**。「宿鳥」仄仄對「鳴蟲」平平：**亦全反**。兩分句各自成工整的平仄相對 |
| 修辭效果 | 動靜、去來、禽蟲三層對比，兼具聲音效果（鴻、燕、鳥、蟲皆可想像其聲），是蒙學「屬對＋辨物」的綜合練習 |

### 第 4 聯　三尺劍，六鈞弓

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**（數目＋量度＋器物，三重對應） |
| 詞性義類 | 三／六（數目）、尺／鈞（量·度制/衡制）、劍／弓（名·器物·兵器） |
| 為什麼能對 | ①數目對數目；②「尺」為長度單位、「鈞」為重量單位（三十斤為一鈞，見《說文》《漢書·律曆志》系統），**量度對量度**；③劍與弓同屬**兵器門**，且皆古之常備兵器。三者層層對應，是本篇**最嚴整的工對之一** |
| 平仄 | 三(平) 尺(仄·入) 劍(仄·去)／六(仄·入) 鈞(平) 弓(平)。**三字位全反**（平仄仄／仄平平） |
| 修辭效果 | 教學上專練「數＋量＋物」的三層屬對，並複習入聲字（尺、六）之仄讀 |

### 第 5 聯　嶺北對江東

| 項目 | 內容 |
|---|---|
| 對仗類型 | **寬對**（兼**正對**）；亦具**當句對**之勢（嶺—江、北—東） |
| 詞性義類 | 嶺／江（名·地理，山地 vs 水域）、北／東（名·方位） |
| 為什麼能對 | ①「北／東」為**方位對方位**，是其一的第1聯之變奏；②「嶺／江」雖同屬**地理門**，但一為山、一為水，義類不及「海／雷」之整，故整體判**寬對**較穩（若以「地理對地理」論，判工對亦可，本文從嚴判寬）。③「嶺北」「江東」皆為地理專稱（江東尤為六朝以來固定地名） |
| 平仄 | 嶺(仄·上) 北(仄·入)／江(平) 東(平)。**平仄全反** |
| 修辭效果 | 由「器物對」轉入「地名對」，示範方位詞在名詞短語中的收束作用 |

### 第 6 聯　人間清暑殿，天上廣寒宮

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**（兼**正對**中的**反對**——人間／天上為空間反義） |
| 詞性義類 | 人／天（名·人事 vs 名·天文）、間／上（名·方位）、清／廣（形）、暑／寒（名·時令·反義）、殿／宮（名·建築） |
| 為什麼能對 | ①「人間／天上」為**方位/空間反義對**（地下 vs 天上），是全聯對眼；②「清／廣」皆形容詞；③「暑／寒」為**時令反義對**，最見巧思；④「殿／宮」同屬**宮室建築門**，工整。<br>〔考〕「清暑殿」為六朝宮殿之名（見於《晉書》及洛陽宮殿記載系統；明代蒙書常借為人間華貴居所之代表），「廣寒宮」為月宮之典（《龍城錄》等唐傳奇系統）。此聯在《聲律啟蒙》（車萬育本）卷一「一、東」中作「**人間清暑殿，天上廣寒宮**」，與劉節本同；而《笠翁對韻·東一》作三字對「**清暑殿，廣寒宮**」。可見此對在明清蒙書中廣泛流傳，句式有繁簡之別 |
| 平仄 | 人(平) 間(平) 清(平) 暑(仄·上) 殿(仄·去)／天(平) 上(仄·去/上) 廣(仄·上) 寒(平) 宮(平)。<br>——第2字「間(平)/上(仄)」、第4字「暑(仄)/寒(平)」、第5字「殿(仄)/宮(平)」皆相對；第1、3字同為平（**失對**）。整體屬寬處，但對眼「暑／寒」「殿／宮」極工 |
| 修辭效果 | 以「人間／天上」「暑／寒」兩組反義作骨架，教「反對」之妙；同時引入宮殿與月宮的文化意象 |

### 第 7 聯　兩岸曉煙楊柳綠，一園春雨杏花紅

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**（數量對＋時令對＋天文對＋植物對＋**顏色對**，五重對應俱全）；上下句皆為獨立寫景，屬**正對** |
| 詞性義類 | 兩／一（數目）、岸／園（名·地理單位）、曉／春（名·時令）、煙／雨（名·天文）、楊柳／杏花（名·植物）、綠／紅（**顏色**） |
| 為什麼能對 | ①「兩／一」「岸／園」為數量與處所對；②「曉／春」時令對；③「煙／雨」天文對；④「楊柳／杏花」同屬**植物門**，且一為「春柳」一為「春花」，正相映發；⑤「綠／紅」為**顏色對**，是全聯最亮之對眼。五層對應全部落在同類或鄰類，**本篇最工整的七言聯** |
| 平仄 | 兩(仄·上) 岸(仄·去) 曉(仄·上) 煙(平) 楊(平) 柳(仄·上) 綠(仄·入)／一(仄·入) 園(平) 春(平) 雨(仄·上) 杏(仄·上) 花(平) 紅(平)。<br>格式：**仄仄仄平平仄仄／仄平平仄仄平平**<br>——第2字：岸(仄)／園(平) 相對；第3字：曉(仄)／春(平) 相對；第5字：楊(平)／杏(仄) 相對；第6字：柳(仄)／花(平) 相對；第7字：綠(仄)／紅(平) 相對。**七字中五位相對**。<br>唯第1字（兩/一）與第4字（煙/雨）上下句平仄相同（仄仄、平平），屬**失對**之變格（律詩中第1字可通融；第4字失對較明顯）。<br>〔異文〕車萬育《聲律啟蒙》卷一作「**夾岸曉煙楊柳綠，滿園春色杏花紅**」（見維基文庫本），與劉節本「兩岸／一園春雨」互異；若作「夾岸」則第1字平仄亦相對。**何者為劉節本原文，因東里書齋劉節本頁面連線失敗未能核，標「存疑」** |
| 修辭效果 | 全篇唯一的**寫景律句**：以「綠／紅」收束，色彩對比鮮明，最宜作學生「顏色對＋數量對」的範例；也是從三字對跨入七言近體句式的橋樑 |

### 第 8 聯（隔句對）　兩鬢風霜，途次早行之客／一蓑煙雨，溪邊晚釣之翁

| 項目 | 內容 |
|---|---|
| 對仗類型 | **工對**中的**隔句對**（四分句兩兩相對：上四字對上四字、下七字對下七字，且上四字又與下四字隔句相應）；「兩鬢風霜／一蓑煙雨」**本身又是句中自對（當句對）**——「兩鬢」與「一蓑」自成一層、「風霜」與「煙雨」自成一層，故本聯同時是**隔句對＋當句對**的複合 |
| 詞性義類 | 兩／一（數目）、鬢／蓑（名·形體 vs 名·器物）、風霜／煙雨（名·天文·氣象）；途次／溪邊（名·地理/處所）、早／晚（名·時令）、行／釣（動·動作）、之（助·虛字）、客／翁（名·人物） |
| 為什麼能對 | ①「兩鬢風霜」寫陸上早行客的形貌（鬢上風霜＝風塵僕僕），「一蓑煙雨」寫水上晚釣翁的裝束（披蓑戴雨），以**部分代全體**（鬢／蓑代整個人）之借代，形象對稱；②「途次／溪邊」為**陸 vs 水**之處所對，「早／晚」為**時間反義對**，「行／釣」為**動 vs 靜**之動作對，三層對比精妙；③「客／翁」同屬**人物門**。整聯是一幅「早行客—晚釣翁」的對照圖 |
| 平仄 | 兩(仄·上) 鬢(仄·去) 風(平) 霜(平) ／ 途(平) 次(仄·去) 早(仄·上) 行(平) 之(平) 客(仄·入)；<br>一(仄·入) 蓑(平) 煙(平) 雨(仄·上) ／ 溪(平) 邊(平) 晚(仄·上) 釣(仄·去) 之(平) 翁(平)。<br>——「兩鬢風霜」仄仄平平 對「一蓑煙雨」仄平平仄：第2字（鬢仄/蓑平）、第3字（風平/煙平？同平，失對）、第4字（霜平/雨仄）相對，第1字同仄。<br>「途次早行之客」平仄仄平平仄 對「溪邊晚釣之翁」平平仄仄平平：第2字（次仄/邊平）、第4字（行平/釣仄）、第6字（客仄/翁平）**全部相對**，第3字（早仄/晚仄）同仄，第5字「之」重字。<br>〔按〕「**之**」於上下聯同位置重複，是《文心雕龍·麗辭》批評的「對句之駢枝」一類**異位/同位重字**；但蒙書為求句式整齊、且「之」為純虛字，不以為病。**此為蒙書與近體律詩要求不同之又一顯例** |
| 修辭效果 | 全篇壓軸：以「早行／晚釣」「客／翁」收束，兼具**時間（早晚）、空間（途／溪）、動靜（行／釣）、人物（客／翁）**四重對照，且四字＋七字的隔句體正是《四庫提要》所說的「隔句各押一韻」之最高階訓練 |

> 〔其二聲律總評〕8 聯中，第 1、3、4、5 聯四聯為嚴格「平仄全反」；第 2、6、7、8 聯各有局部失對（多在第 1、3、4 字位），但**對眼所在之字位（顏色、反義、數目）皆平仄相對**。可見此段教學重點在「**對眼工整、聲律從寬**」。全篇亦**無典型拗救**。

## 三、總結：16 聯涉及的對仗範式與對課教材知識點

### （一）16 聯對仗範式統計

| 範式 | 出現聯數 | 具體聯 |
|---|---|---|
| **工對** | 10 | 其一 1、2、3、4、5、6、7、8；其二 1、2、3、4、6、7、8（其中多聯兼類） |
| **寬對** | 3 | 其一 8（末句局部）、其二 5（嶺北／江東）、其二 6（人間清暑殿／天上廣寒宮，第1、3字失對） |
| **正對** | 11 | 其一 3、4、5、6、7；其二 1、2、3、4、5、6、7 |
| **反對** | 5 | 其一 1（南北）、2（外中）、8（有象／無窮）；其二 3（來／去）、6（人間／天上、暑／寒）、7（綠／紅） |
| **當句對（句中自對）** | 1（＋1 兼具） | 其二 8「兩鬢風霜／一蓑煙雨」；其二 3、5、7 亦具當句對之勢 |
| **隔句對** | 1 | 其二 8（四字＋七字隔句）；其一 8 亦為隔句體 |
| **流水對** | **0** | 兩段 16 聯皆上下並列、可獨立，無「上下相承、不可倒置」之流水句。**此點須向學生明說：蒙書以「正對／反對」為訓練主體，流水對屬後來近體詩與律賦之發展** |

〔說明〕一聯往往兼跨數類（如「南對北」既工對又反對），故各類統計之和不等於 16。

### （二）可作對課教材的知識點（按教學梯度）

1. **義類體系（辨類）**：本段 16 聯恰好覆蓋《詞林典腋／詩韻合璧》體系中的主要門類——天文（雲雨雪風、煙雨）、時令（曉、春、早、晚）、地理（海嶽、嶺江、岸園、途次溪邊）、人事（君臣父子、德功）、人物（堯舜禹湯、孔子周公、客翁）、動物（鴻燕鳥蟲）、植物（楊柳杏花）、器物（劍弓、蓑、殿宮）、數目（三五、六千百、兩一）、方位（南北東、外中、間上）、顏色（綠紅）、形體（鬢）、動作（來去、宿鳴、行釣）、虛字（之、於、有無）。**一份教材即涵蓋十三類，密度極高。**
2. **屬對語法（審結構）**：並列對並列（君臣／父子、海嶽／雷風）、偏正對偏正（物外／寰中、晚照／晴空）、動賓對動賓（結繩／畫卦、行／釣所屬）、主謂對主謂（六經千古在／五典百王同）、「數＋量＋物」三層對（三尺劍／六鈞弓）。
3. **平仄（審音）**：入聲歸仄之要（北、物、嶽、德、六、百、雪、尺、綠、一、宿、客、結、畫、育）；「平對仄、仄對平」在句內的落實；**由嚴入寬的階梯**（2—5 字嚴、7 字與隔句寬）；**蒙書不嚴守近體句腳規則**（其一第3聯末字俱仄）、**允許同位重字**（「之」「於」）——這正是「蒙書」（《聲律發蒙》）與「律詩」（王力《漢語詩律學》所述）在聲律要求上的分界，須反覆向學生點明。
4. **對仗美學（識高下）**：《文心雕龍·麗辭》「**反對為優，正對為劣**」之評準——本段「來／去」「南／北」「外／中」「有象／無窮」「綠／紅」皆反對之優者；「君臣／父子」「堯舜德／禹湯功」則正對之穩者，正可作優劣比較之教材。
5. **用典（明出處）**：「書代結繩」出《易·繫辭下》、「圖呈畫卦」出《易·繫辭上》與《說卦》系統、「海嶽／雷風」出《說卦》第三章（「天地定位，山澤通氣，雷風相薄」）；教學上可示範「**無典亦可對，有典則更厚**」。
6. **蒙學終極目標**：以「**辨義類、審音、屬對**」三事合一，使童子日課一韻，由一字至七字再至隔句（《四庫提要》所謂「自一字七字至隔句各押一韻」），最終能自作律聯。

## 五、存疑事項一覽（嚴禁編造，故特為標出）

1. **「寰」的平仄**：平水韻系統作平聲刪韻（音環），但《廣韻》《集韻》另有去聲霰韻「同縣」一讀。本聯取平聲（「物外／寰中」為平仄相對），若取去聲則該字位失對。
2. **「溪」的平仄**：維基文庫《平水韻》表未收「溪」字；《廣韻》為平聲齊韻（苦奚切），本文取平，並註明此據他本韻書。
3. **其一第8聯「書代結繩／圖呈畫卦」是否另有更早的現成對句來源**：未見確證，標存疑。
4. **「六經／五典」是否化用某一固定成句**：僅能證「五典」見《左傳·昭公十二年》「三墳、五典、八索、九丘」，「六經」為常語，**兩者對舉之最早出處未詳，存疑**。
5. **「海嶽／雷風」的典故判定**：可確證「雷風」與「山澤」同出《易·說卦》對待之列，故「雷風」有典；但「**海嶽**」非《說卦》原詞，是以「山澤」推擴而來。故此聯為「**用《易》理而成的事對**」，而非直接襲用《說卦》成句。此一界限已於第4聯說明。
6. **其二第7聯「兩岸／一園」與車萬育本「夾岸／滿園春色」之異文**：何者為劉節本原文，因劉節本原頁未能訪問，存疑待核。
7. **「清暑殿」的具體出典**：可確定為六朝宮殿名（《晉書》系統），但其與「廣寒宮」成對之最早蒙書出處，本文未及確證，存疑。

> 〔附〕本文平仄標記所用規矩為：平＝平聲（上平／下平），仄＝上、去、入三聲；入聲字特別標「(入)」。凡屬「一三五不論、二四六分明」可通融處，已逐聯指出；**兩段 16 聯皆無典型拗救**（拗救為近體律詩之制，蒙書屬對不適用）。
