# 内容与页码约定

> 页码、ID、命名与注譯内容结构的**唯一权威说明**。
> 任何脚本、内容文件都必须遵守；改动前先改本文。

---

## 1. 页码方案

### 1.1 三类页面

| 页面 | 页脚显示 | 说明 |
|---|---|---|
| 封面 | *（空）* | 卷首扉页，不占页码 |
| 前置 | `卷一 · 前置 1 / 2` | 題解、序言（仅卷一有） |
| 正文 | `卷一 · 3 / 30` | 原文页，**卷内独立编号** |

### 1.2 为什么正文页按"卷内独立序号"

注解与翻译是**逐篇后补**的。若正文页码用全卷总序号（含注解页），
每补一篇注解，后面所有页码都会移位，已交付/已引用的页码全部失效。

因此规定：

- **正文页编号只在正文序列内递增**，与注解无关。
- 注解页使用**子编号**，形如：

  ```
  卷一 · 3 · 注 1
  卷一 · 3 · 注 2
  卷一 · 3 · 注 3
  ```

- 注解尚未产出的，**不占位、不编号**（保持 deck 干净）；
  需要预留可见空位时用 `build_deck.py --slots` 生成占位页，
  占位页页脚为 `卷一 · 3 · 注`（无序号，因为篇数未定）。

> 单篇注解的页数不固定（一東一篇用了 3 页）。因此**不预留固定张数**，
> 而是靠"正文独立编号 + 注解子编号"保证任何情况下正文页码稳定。

### 1.3 当前规模

| 卷 | 韵目 | 段数 | 正文页 | 封面 | 前置 | 合计 |
|---|---|---|---|---|---|---|
| 卷一 | 15 | 60 | 30 | 1 | 2 | 33 |
| 卷二 | 15 | 60 | 30 | 1 | 0 | 31 |
| 卷三 | 29 | 99 | 58 | 1 | 0 | 59 |
| 卷四 | 30 | 100 | 60 | 1 | 0 | 61 |
| 卷五 | 17 | 57 | 34 | 1 | 0 | 35 |
| **合计** | **106** | **376** | **212** | 5 | 2 | **219** |

> 正文页数按「分页不跨韵部」计算：`Σ ceil(该韵段数 / 2)`。

## 2. 标识符（slide id）

### 2.1 正文页

```
j{卷号}-{韵目}-{起始段号}
```

例：`j1-一東-1`（卷一·一東·第1段起）、`j3-二十哿-3`。

- **绑定内容而非位置**：即使将来改了每页段数、插入了注解页，这个 id 都不变。
- 注譯页组、外部引用、未来做目录跳转，一律用这个 id。

### 2.2 注解页与占位页

- 注解页：`{正文页id}-anno-{k}`（k 从 1 起）
- 占位页：`{正文页id}-slot`

## 3. 注譯内容 JSON

**位置**：`data/annotations/{卷号}-{韵目}.json`，例：`1-一東.json`。

**绑定**：文件内的 `target` 字段指向正文页 id；`make_annot.py` 据此取原文。

### 3.1 完整结构

```jsonc
{
  "target": "j1-一東-1",        // 绑定的正文页 id
  "juan": "卷一",
  "rhyme": "一東",

  "pages": {
    // ── 第 2 页：譯文 + 題旨/補說/屬對法度 ──
    "trans": {
      "trans": [                       // 顶部通栏译文，每项一列
        { "label": "其一 · 文明與道統", "text": "南與北相對，北與東相對。…" }
      ],
      "columns": [                     // 下方注釋栏（可 2–4 栏）
        { "title": "題旨", "flex": 0.92,
          "notes": [ { "tag": "題旨", "term": "其一", "text": "…" } ] },
        { "title": "屬對法度", "flex": 1.0,
          "pairs": [ { "t": "南／北・北／東", "d": "方位對方位，以「北」字頂針相銜。" } ] }
      ]
    },

    // ── 第 3 页起：逐段詳注（一段一页） ──
    "stanzas": [
      {
        "label": "其一",
        "lines": ["南對北，北對東。", "…"],   // 原文条，逐行
        "rusheng_set": "北物嶽德六百育結畫",    // 需标朱的入声字
        "columns": [
          { "title": "典源", "notes": [ { "tag": "典源", "term": "物外／寰中", "text": "…" } ] },
          { "title": "語詞・注音", "notes": [ { "tag": "注音", "term": "寰", "text": "<span class=\"py\">huán</span>…" } ] },
          { "title": "對仗與平仄", "pairs": [ { "t": "…", "d": "…" } ] }
        ]
      }
    ]
  }
}
```

### 3.2 字段规则

| 字段 | 必填 | 说明 |
|---|---|---|
| `tag` | 否 | 行首胶囊标签，2 字最佳（典源／注音／對仗／辨正／版本／音韻／異文…） |
| `term` | 否 | 加粗词条，可省略 |
| `text` | 是 | 正文；允许 `<b>`、`<span class="py">`（拼音）、`<span class="src">`（按语/辨正） |
| `flex` | 否 | 该栏宽度权重；用于平衡各栏高度（省略即 1） |
| `notes` / `pairs` | 二选一 | 编号条目 / 词条+理据的紧凑列表 |

**编号是自动的**，跨栏连续，不要在 `text` 里手写序号。

### 3.3 禁用项

- 不允许 `<script>`、行内 `style`、外部资源（图片/字体 CDN）。
- 不允许写死宽度、字号；版式由 `make_annot.py` 的 CSS 决定。

## 4. 命名约定

| 类别 | 规则 | 示例 |
|---|---|---|
| 卷 HTML | `卷{汉字}.html` | `卷一.html` |
| 样张 HTML | `一東{用途}.html` | `一東注譯四頁.html` |
| 截图 | `page-{序号}.png` | `page-3.png` |
| 注譯 JSON | `{卷号}-{韵目}.json` | `1-一東.json` |
| 考据报告 | `{主题}考證.md` | `音韻校注.md` |

- 韵目一律用**繁体刻本原字**（含异体：`十三間`、`二十九豔`、`十七恰`），
  不要改为通行平水韵目（`問`、`艷`、`洽`）——那会与正文对不上。
- 文件名允许中文；脚本内引用一律通过 `paths.py` 或参数传入，不拼接字符串。

## 5. 推进注譯的标准流程

```
1. 建 data/annotations/{卷号}-{韵目}.json（先填 target / juan / rhyme）
2. 六路并行考据 → research/考據報告/ 落盘
3. 合并考据（注意：冲突结论要显式取舍并说明，不可两边都写）
4. 填 JSON 内容（译文 + 分栏注释）
5. python3 src/make_annot.py data/annotations/{卷号}-{韵目}.json
6. python3 src/check_deck.py <产物>   # 必须 0 问题
7. 截图目视复核 → 交付
```

考据分工参考（一東篇已验证有效）：

| 路 | 任务 |
|---|---|
| 1 | 其一：典故与语源（逐条给出处+原文） |
| 2 | 其二：典故与语源 |
| 3 | 音韵：入声字（广韵反切/韵部）、生僻字注音、平仄、押韵校验 |
| 4 | 对仗：逐联类型、词性义类、为什么能对、平仄 |
| 5 | 作者与版本：著录、版本链、异文 |
| 6 | 诗词意象渊源：句子在唐宋诗词中的渊源，区分"确有出处"与"义类相对" |
